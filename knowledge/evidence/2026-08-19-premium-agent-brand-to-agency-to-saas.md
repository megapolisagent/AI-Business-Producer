# 2026-08-19 — Практика: личный бренд риелтора → агентство → SaaS для риелторов

> Собрано агентом-специалистом (general-purpose, веб-исследование) по узкому брифу, зафиксированному до поиска в `OPEN_QUESTIONS.md` (запись 2026-08-19). Полный ответ — в истории задачи; здесь только выжимка для повторного использования.

## Вопрос
(а) Как отдельные риелторы премиум/элит-сегмента реально строили агентство с нуля через личный бренд/контент, без капитала и платной рекламы.
(б) В каком порядке такие агенты потом строили ИИ-инструмент/SaaS для других риелторов.

## Подтверждено источниками

- **Ryan Serhant** (Нью-Йорк, люкс): контент вместо холодных звонков с 2008 → своя брокерская компания SERHANT в 2020 → AI-SaaS S.MPLE в 2024 ($45M раунд). Прямое совпадение с порядком «бренд → агентство → SaaS». [Forbes](https://www.forbes.com/sites/carminegallo/2021/07/27/how-a-struggling-actor-became-a-real-estate-agent-in-a-122-million-house-sale/), [AlleyWatch](https://www.alleywatch.com/2024/12/s-mple-ai-powered-saas-assistant-real-estate-professionals-administrative-tasks-automation-ryan-serhant/)
- **Chad Carroll** (Майами, люкс): личный бренд через соцсети/реалити с 2008 → команда/агентство, без прохождения до SaaS. [RISMedia](https://www.rismedia.com/newsmaker/chad-carroll-2026/)
- **Никита Лабецкий** (СПб, Россия): личный бренд + YouTube → агентство «Лабецкий Недвижимость» (100+ квартир/мес). Ранний этап (был ли бюджет на старте) в источниках не раскрыт — пробел.
- **Brandon Wise / Wise Agent**: CRM основана прямо из практики агента, **минуя стадию «своё агентство»** — другой порядок.
- **Dalton Brewer / SetWave** (2025): действующий брокер, сделал AI-инструмент **параллельно практике**, не строя сначала агентство — другой порядок.

## Явно не найдено (не путать с опровержением)
Именованный премиум/элит-кейс из Москвы/России с детализацией пути «бренд → агентство» — не найден. Это пробел в доказательной базе, не факт «так не работает».

## Вывод для использования в teardown
Порядок «личный бренд → агентство → SaaS» — реально встречается и один раз подтверждён очень сильным примером (Serhant), но **не единственный проверенный путь**: переход в SaaS у части агентов происходит раньше или параллельно, без отдельной стадии «сначала агентство». Держать как вероятный, обусловленный путь, не как гарантированный.
