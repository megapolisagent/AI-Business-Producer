# История и статус решений

> Не журнал. Действующий механизм: `HOME.md` и `UPDATE.md` обязаны сверяться с этим файлом в определённых сценариях, а не просто могут его почитать при желании.

## Как решение становится фактом

```
Proposal → Discussion → Locked
```

Переход между статусами разрешён только по явному подтверждающему слову владельца («принимаем», «фиксируем», «зафиксируй», «LOCKED») — никогда не выводится из тона реплики и никогда из того, что идею предложил сам владелец.

## Правила

- **Отклонённые альтернативы не удаляются.** Остаются в записи со статусом «отклонено» и причиной.
- **После Locked — заморозка.** Обсуждение отклонённых вариантов прекращается немедленно. Снять заморозку может только явная команда владельца или прямой провал уже принятого решения на практике.
- **Решение не пересматривается без нового факта.**
- **Высокий радиус поражения — пропорциональная проверка.** Решения, меняющие направление бизнеса или методологию работы агента, требуют проверки до Locked, глубина — пропорциональна масштабу риска.

## Формат записи

```
### {дата} — {короткое название решения}

Статус: Proposal / Discussion / Locked / Отклонено
Что решается:
Обоснование:
Отклонённые альтернативы:
Источник:
```
