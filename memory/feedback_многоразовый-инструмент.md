# Правка: многоразовый инструмент

Дата: 2026-08-17
Было: не было ясно, собирается ли агент под конкретный бизнес владельца или как переиспользуемый инструмент.
Правка владельца: «Многоразовый инструмент» — прямой ответ на уточняющий вопрос Engineer.
Правильно: `knowledge/businesses/<слаг>.md` — не единственный файл про один бизнес, а расширяемая папка; агент должен уметь начать новый разбор для другого дела владельца, не переписывая себя заново.
